# Mohammad Ali Ismael — Portfolio Website

A responsive one-page portfolio inspired by the supplied dark/red reference video and built from Mohammad Ali Ismael's CV content.

## Included
- Sticky glass navigation and scroll progress
- Hero section with stylized personal portrait visual
- About statement and statistics
- Interactive capability pills
- Animated 3D CSS cube feature section
- Work + education timeline
- Filterable technical skill cards
- Training/courses section
- Four project cards with real GitHub repository links
- Contact card, LinkedIn, email, phone, WhatsApp
- Contact form that opens the visitor's email app
- Responsive mobile navigation
- Reduced-motion accessibility support
- Original CV included in `assets/Mohammad_Ali_Ismael_CV.pdf`

## Run locally
Open `index.html` in a browser. No build step or server is required.

For best local testing you can also run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Optional final polish
The hero uses a stylized personal portrait with the dark red cinematic treatment requested for the portfolio.

The project cards use custom local visual mockups. Replace them with real project screenshots later if you want an even closer portfolio presentation.
